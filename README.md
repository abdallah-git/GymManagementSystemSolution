# 🏋️ Gym Management System (Power Fitness)

An integrated management system designed to streamline gym operations, member subscriptions, and session scheduling. Built with a robust **3-Tier Architecture** to ensure scalability and maintainability.

## 🚀 Key Features
* **Member Management:** Register, update, and track gym members.
* **Subscription Plans:** Manage different tiers (Basic, Standard, Premium) with dynamic pricing.
* **Session Scheduling:** Create and manage workout sessions (Yoga, Boxing, General Fitness) with real-time capacity tracking.
* **Trainer Portfolios:** Manage professional instructors and their specialties.


## 🏗️ Technical Architecture
The project follows the **N-Tier Architecture** pattern:
1.  **GymManagement.PL (Presentation Layer):** ASP.NET Core MVC with a responsive UI.
2.  **GymManagement.BLL (Business Logic Layer):** Handles the core services and logic.
3.  **GymManagement.DAL (Data Access Layer):** Manages database operations and entities.

## 🛠️ Technologies Used
* C# | ASP.NET Core MVC
* Entity Framework Core
* SQL Server
* Bootstrap & Modern UI Components
